## Ver.0.1.8 変更点

- 主人公の「水脈の雫／水脈の恵み」をアクティブMP回復から「水脈吸収（パッシブ）」へ変更。短剣で敵にダメージを与えるとLv.1でMP+1、Lv.2でMP+2回復します。
- 氷結斬りの発動中は完全無敵になりました。
- 氷結斬りは発動時に最寄りの敵へ自動で向かい、多段時は1段ごとに最寄りの敵を再検索して連続斬りします。
- 氷結斬りの通常1→2→3回、九尾時3→6→9回の仕様は維持しています。


## Ver.0.1.7 変更点

- 主人公のスキル強化SPを少し重く調整。氷結斬りはLv2にSP2、Lv3にSP3。氷弾系も2→3→4SPなど段階式に変更。
- 氷結斬りは通常時 Lv1=1回、Lv2=2回、Lv3=3回の高速ダッシュ斬り。各移動ごとに青い線の残像を1本残す。
- 氷結斬りはLv3で打ち止め。4回目の通常強化は作らない。
- 九尾の力は氷結斬りの現在回数を3倍する方式。Lv1なら3回、Lv2なら6回、Lv3なら9回。
- 九尾Lv3の最終形が9回連続高速移動になる。


Ver.1.35をベースに、既存イベント・マップ・セーブ進行をできるだけ残しつつ戦闘をリアルタイムARPG化した試作です。

## 操作
- 移動: WASD / 矢印 / スマホ左スティック
- 短剣: J / 左上の丸い「短剣」
- 氷結斬り: K / 「氷結斬り」
- 氷弾: L長押し→離す / 「氷弾」長押し→離す
- 最大までチャージすると広範囲氷魔法
- 自己回復: H / 「回復」
- AI・SP設定: P / 右上「AI / SP」

## 仲間
- 仲間にHP・MPはなく、戦闘不能になりません。
- スズマル: 剣攻撃 / 火炎斬り / 範囲炎魔法
- ユーノ: 弓攻撃 / 風範囲魔法 / 主人公回復 / 主人公MP回復
- ジュウ: 槍攻撃 / 主人公の近くで盾を構えて攻撃を防ぐ
- 仲間スキルにはクールタイムがありますが、クールタイム終了直後に機械的に必ず使うことはありません。距離、敵数、主人公HP/MP、ランダムな判断間隔を見て行動します。
- AI / SP画面で行動優先順位を上下に変更できます。

## 育成
既存の各キャラクターSPを使用します。主人公の強化は段階に応じて必要SPが増え、氷結斬りはLv.3までです。仲間側はARPG用Lv強化を継続します。

## 注意
これは戦闘感触確認用の試作です。既存の全イベント・全ボスを完全にARPG向け再調整した完成版ではありません。敵の攻撃パターンやボス固有ギミックは今後の調整対象です。


## Ver.0.1.7 変更点
- 氷弾の発射数強化を修正。旧スキルツリーの「氷つぶて乱射」強化とARPG側強化を同期し、1発 → 3発 → 5発 → 7発になります。
- ユーノ「疾風（1人を2回行動）」を廃止。既存セーブで習得済みの場合は使用SPを返却します。
- スズマル「炎返し（反撃）」を廃止。既存セーブでは使用SPを返却します。
- ジュウ「大地の息吹（毎ターンHP回復）」を廃止。仲間にHPがないARPG仕様に合わせ、既存セーブでは使用SPを返却します。
- ユーノのパッシブ「風巡の呼吸」を「風脈支援」に変更。戦闘中、主人公MPがLv1で約0.5/秒、Lv2で約0.9/秒ずつ回復します。
- スズマル「闘炎」はARPG用パッシブとして整理し、Lv1で炎スキル威力+6%、Lv2で+12%に変更しました。
