# りすぺく島ARPG 試作 Ver.0.1.17

## Ver.0.1.17 変更点
- ユーノが「追い風（全員の移動速度アップ）」と「魔力の風（主人公MP回復）」を両方使用可能。
- 「そよぎの輪（徐々にHP回復）」を廃止。既存習得分はSP返却。
- 追い風はLv.2で効果時間・速度倍率・クールタイムが強化。
- 天風の祝福（HP/MP50%回復＋全員加速）は継続。

- 火山の古竜を大型キャラ分の余白込みで画面内に固定。
- ユーノの風刃嵐を緑色の円形波に変更し、命中時ノックバックを追加。AI使用率も改善。
- 追い風のスキルツリー強化クリックが誤ったキーを参照していた不具合を修正。
- 主人公・仲間のクールタイム回復速度を約18%高速化。
