# りすぺく島ARPG 試作 Ver.0.1.22

## Ver.0.1.22 修正点
- 初回の通常戦闘後にダッシュミウ単独のworld（ぶりふぉ村前）へ戻り、進行不能になる不具合を修正。
- 戦闘開始時に「戦闘を開始したシーン」を保存し、通常戦闘終了時は必ずその場所へ戻るよう変更。
- ぶりふぉ村を出発してroad2へ移った時点で安全セーブを作成。
- v0.1.21以前で進行不能状態になったセーブは、ロード時にぶりふぉ村の会話へ復旧して進行可能にする救済処理を追加。
- キャッシュキーを Ver.0.1.22 に更新。

## Ver.0.1.22 修正点
- 主人公の氷弾1発あたりの威力を大きめに底上げ。多弾化しても主力火力として使えるよう調整。
- スズマル奥義「紅蓮爆砕」をARPG仲間AIへ追加。習得済みならAI優先度最上位で、クールタイム終了ごとに即発動。
- 紅蓮爆砕を三連炎撃＋多重の炎リング＋大型火炎斬撃残像で派手に演出。
- 紅蓮爆砕のクールタイムは約11.5秒（全体CT加速の影響を受け、実効はさらに短め）。
- キャッシュキーを Ver.0.1.22 に更新。
